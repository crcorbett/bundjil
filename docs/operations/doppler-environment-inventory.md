Cooper's current continuation approval permits one cleanup only after this PR
is merged and both exact hosted paths are independently proved. It may remove
only the five legacy GitHub secret copies and four legacy GitHub variable
copies named above. It must first read back the Doppler project/config names,

must not delete Vercel runtime variables, Personal recovery items, provider
credentials, Alchemy state or unrelated GitHub Environment entries. Removing
the one-operation `stg_repair` config is a separate provider cleanup and is not
authorised by this approval.
