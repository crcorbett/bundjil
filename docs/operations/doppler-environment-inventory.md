## Cleanup boundary

After this PR is merged and the exact hosted paths are independently proved, a
separate approved cleanup may remove only the now-unused legacy GitHub names.
That cleanup must first read back the Doppler project/config names, token
scope/expiry, GitHub secret-name inventory, exact workflow source and hosted
receipt. It must not delete Vercel runtime variables, 1Password recovery items,
provider credentials, Alchemy state or unrelated GitHub Environment entries.
